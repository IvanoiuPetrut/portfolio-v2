## Overview

Game Shelf is a web app for searching video games and reading about them. It gets its data from the RAWG Video Games Database API.

## What you can do

- Browse lists of games picked by different criteria
- Search for a specific game across categories
- Read the details of any game
- See every game made by a developer or released by a publisher

It is built with Vue 3 and the Composition API, Pinia for state, Axios for the API calls and SASS for styling.
