## Overview

Chrono Switch is a 2D pixel art platformer. The player can shift time to reveal hidden paths, and the level asks for faster, more precise switching as it goes. It is built with JavaScript and Phaser, and the source is open on GitHub.

## Controls

Arrow keys move, Space jumps and C shifts time.
