## Overview

Atlas Clinics' internal admin dashboard had become painfully slow. The worst report screens took eight seconds to load, and staff had started exporting data to spreadsheets just to get work done.

I was brought in for a fixed six-week engagement to find the bottlenecks and fix them without a rewrite.

## The challenge

- **No rewrite budget.** Fixes had to land in the existing React and .NET codebase.
- **Live system.** Clinics used the dashboard all day, so every change had to be safe to release.
- **No baseline.** There were no performance metrics to start from.

## Approach

Week one was measurement only. I added tracing to the API and real-user timing to the front end, then ranked screens by total time wasted per day.

The biggest wins came from three places:

1. **N+1 queries.** One report issued over 900 queries per load. A single joined query replaced them.
2. **Missing indexes.** Two composite indexes cut the slowest query from 3.1 s to 40 ms.
3. **Over-fetching.** The front end loaded full patient records to show a name. Slim view models fixed that.

## Outcome

Median page load dropped by 76%, and the worst report screen went from 8 seconds to 1.9. Every change shipped behind a feature flag, and none needed rolling back.
